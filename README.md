E-Commerce Sales Analysis & Interactive Dashboard

A comprehensive data analytics project featuring an end-to-end exploratory data analysis (EDA), descriptive statistics, and an interactive Excel dashboard tracking sales performance, regional metrics, customer segments, and store performance from 2023 to 2025.

📊 Project Overview

This repository contains transactional data, statistical summaries, and visual dashboards designed to uncover key business insights for an e-commerce retail operation. The project evaluates sales trends across multiple dimensions, including product categories, store types, customer loyalty tiers, and geographical regions.

E-Commerce Sales Dashboard Insights

The accompanying interactive Excel dashboard features dynamic slicers (Category, Gender, Store Type, Store Name, Region, Loyalty Level, State, Order Date, and Quantity) to filter and analyze KPIs in real time:

Category Performance: Tracks total sales volume across product categories like Beauty, Clothing, Electronics, Home, and Sports.

Gender-Wise Sales: Analyzes consumer purchasing distribution (e.g., Female customers accounting for $57\%$ ($1,229,710$) vs. Male customers at $43\%$ ($940,382$)).

Store Type & Revenue: Compares performance across Flagship, Online, and Outlet store formats using dual-axis volume and revenue metrics.

Regional Trends (2023–2025): Evaluates year-over-year growth across East, North, South, and West regions.

Loyalty Level Quantity Sales: Breaks down order quantities by customer loyalty tier (Bronze, Silver, Gold, Platinum, and Unknown).

State-Wise Average Discount: Monitors discount variation trends across different operating states.


🛠️ Built With

Microsoft Excel: Pivot Tables, Pivot Charts, Slicers, and Descriptive Statistics Analysis ToolPak.

Markdown: Documentation and reporting.
